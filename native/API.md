## Sparse matrices

`Sparse` is a compressed sparse matrix (pycli `la_sparse`). Build it from COO triplets (duplicates add up, like scipy) or entry by entry, then solve directly (`solve`, SuperLU-style sparse LU), iteratively (`cg`, `gmres`, `bicgstab`; options `rtol`, `atol`, `maxiter`, `x0`, gmres `restart`) or find eigenvalues of a symmetric matrix (`eigsh`, implicitly restarted Lanczos as in ARPACK).

### Functions

| Signature | Meaning |
|---|---|
| `sparse(int, int) -> Sparse` | empty rows x cols sparse matrix (fill with `add`) |
| `sparse(Vec, Vec, Vec, int, int) -> Sparse` | from COO triplets (row indexes, column indexes, values, rows, cols); duplicates are summed |
| `sparse(Mat) -> Sparse` | from a dense matrix (zeros dropped) |
| `speye(int) -> Sparse` | n x n sparse identity |

## Statistics

Probability distributions (pycli `stats_dist`, `stats_dist_to`), special functions (`special_fn`, `special_fn_to`), numpy-compatible random numbers and classical tests. Distributions follow scipy.stats 1.16 parameter names and formulas (each family is a port of its scipy class; special functions are scipy's own xsf/Cephes code or Boost.Math with scipy's policies). `dist(name, opts)` takes the scipy parameters plus `loc` (and `scale` for continuous families); pycli's names are accepted too: uniform `low`/`high`, gamma `shape`, lognorm `mu`/`sigma` (of the underlying normal), poisson `lam`. ## Optimisation, roots, quadrature and linear programming

Objectives, models and equations are expression strings in pycli's grammar; the unknowns are named by a StrVec, and option keys starting with `$` bind constants and data vectors (`opts().set("$x", xs)`). Every expression evaluation counts against `max_evals` (default 500000) and the optional `time_limit` (seconds); a stopped run reports the best point so far.

## Ordinary differential equations

Initial value problems dy/dt = f(t, y) with expression right-hand sides (pycli `ode_solve`, `ode_solve_to`; scipy.integrate.solve_ivp). `rhs[i]` is the expression for d(state[i])/dt in the state names, `t`, `y[i]` and `$`-bound constants (`opts().set("$beta", 0.3)`). Methods RK45 (default), RK23, DOP853, Radau, BDF are ports of scipy's solvers (same step control, dense output and finite-difference Jacobian); LSODA is an automatic switch from RK45 to BDF when Hairer's stiffness test fires, not ODEPACK. Result statuses: OK, STEP_SIZE_TOO_SMALL, NO_CONVERGENCE, EVAL_LIMIT, STEP_LIMIT, EVENT_LIMIT, NON_FINITE (a NaN/inf RHS or event value stops the run); a non-OK run keeps the samples computed so far and ends at the last accepted state.

## Interpolation

1-D interpolants and n-D radial basis functions (pycli `interp_eval`, `interp_eval_to`; scipy.interpolate). `interp(kind, x, y[, opts])` builds an `Interp` once; evaluate, differentiate and integrate it as often as needed. ## Statistical models

## Machine learning
