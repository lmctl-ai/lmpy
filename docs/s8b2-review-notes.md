## Declined

**Fable m6 (fuzz): "OUTPUT_TOO_LARGE for a 451-node inline listing from records comes from the worker, not pre-spawn".** Wrong: the probe's message ("listing the distances of 451 nodes exceeds the inline budget (limit 450 nodes): give a target or use graph_paths_to") is the C++ text of `prepare_graph_paths` (src/s8g.hpp), emitted before any spawn for both the frame and the records form; the exit code 1 is the documented COMMAND_FAILED class of OUTPUT_TOO_LARGE, which the reviewer mistook for a worker crash. `GraphReview.test_output_too_large_is_command_failed_with_a_usable_hint` runs that case with a missing interpreter to pin the pre-spawn rejection.

## Cross-slice notes
Argon's non-ranked coherence suggestions (defaults for `from_column`/`to_column`, a `frame` input for the `sm_*` operations, the `squeeze` default of `frame_to_array`) are additive API changes outside this round; the S8b-2 contracts are unchanged apart from the corrections above.
The two-stream samplers change the variates of nct, skewnorm, betabinom and levy_stable for a given seed relative to 52f0267 (the one-stream scipy draw did not have the documented prefix property); every other family's stream is unchanged (golden streams in the tests).
