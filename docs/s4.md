# S4: LP/MILP + ODE (review-fixed)

See README for the current input, output, limits and status contract, and
review-s4-fixes.md for every review disposition and the acceptance record.

The original static-write/automatic-artifact design is superseded by S1-style
read `opt_linprog` / `ode_solve` and write `_to` twins with required exclusive out.
Read forms never write: overflow recommends `_to`, including under readonly.
Write forms always produce vector artifacts or fail; dryrun/readonly are enforced
by lmcpp before work. outputs_in_artifact distinguishes inline arrays and refs.

C++ validates shapes, budgets, expression ASTs, finite magnitude <=1e15, scaled
RHS <=1e15 and coefficient ratios >=1e-9 before spawning. HiGHS receives row and
objective normalized data and a small_matrix_value of1e-12. Original data remain
available for relative primal and LP KKT checks. Original-unit marginals and MIP
bounds are restored before returning. No input coefficient is silently removed.
Native model-status IDs are decoded from the pinned SciPy adapter's fixed message
suffix; status2 model error and status9 ambiguity are kept distinct.

The original-data certificate uses long-double accumulation: each row's scale is
abs(b)+sum(abs(a*x)), bounds use abs(bound)+abs(x), stationarity uses the sum of
absolute objective/dual contributions, and duality gap uses absolute primal/dual
objective terms. Only the long-double minimum positive normal is a denominator
floor, not a caller-unit absolute tolerance. Relative tolerance1e-7, integrality
absolute1e-6. Integer rounding is followed by original-data feasibility checks.
LP dual signs, stationarity, complementary slackness and objective gap must pass
before returning OK with duals. MILP retains native gap/bound provenance; it is
not independently certified by solving another integer problem.

ODE still uses solve_ivp with one of six closed OdeSolver subclasses. Every RHS
component and event value, including Jacobian initialization and root bisection,
goes through Guard. Accepted steps and native nfev/njev/nlu are snapshotted in
finally blocks; rhs_calls includes Jacobian calls omitted from native nfev.
Every non-OK status is marked termination:failed / partial_trajectory:true.
A callback stop returns initial + last accepted state, with earlier history lost.
Terminal event output uses the localized root rather than the enclosing step.

For a finite event value zero exactly at t0, the callback substitutes an internal
NaN *after* checking the caller's value, suppressing the initial crossing test in
the pinned solve_ivp implementation. At the first later accepted endpoint normal
comparisons resume. A real NaN/Inf caller expression still stops NON_FINITE.
Like solve_ivp, sign changes do not guarantee detecting multiple roots inside a
single adaptive step; callers should bound max_step when root frequency matters.
Event IDs are inline JSON integers or I64 tensors, up to128 total event records.
The generated grid uses extended-precision linear interpolation with exact
endpoints, then removes equal adjacent double timestamps. Forward and backward
short intervals at large offsets therefore remain valid; grid size is reported.

## Independent oracles

* Wyndor hand optimum (2,6), objective36; diet/production intersection (2,1), cost4.
  Degenerate LP checks objective/feasibility, not a particular nonunique x.
* Inequality/equality/bound marginals checked by perturbing RHS/bounds. Binary
  knapsack enumerates every subset; 3x3 assignment enumerates every permutation.
* Decay exp(-t) for every method; backward decay; oscillator cos(t)/-sin(t) and
  energy; Lotka-Volterra H=d*x-g*log(x)+b*y-a*log(y), DOP853 rtol1e-10, drift<1e-6.
* Robertson at t40: primary ODEPACK DLSODA example in
  https://netlib.org/odepack/opkdmain.f, line3931, SHA256
  da31255ff43e3a13c2c0ccaed51c3cd260b8ac9d9082f34b8587c9007d9a2376.
  Printed (0.7158403, 9.186334e-6, 0.2841505) comes from its loose RTOL1e-4 run;
  printed digits are **not** certified accuracy. Tests use 3e-5 /2e-9 /3e-5 absolute
  tolerances justified by that source accuracy, plus mass conservation1e-11.
  Both BDF/Radau run at rtol1e-10/atol1e-13. The primary-source extraction is kept
  in tests/fixtures/robertson-source.json; acquired only during image build.
* Ball fall terminal root sqrt(2*h/g), time and root state; zero event reaches the
  event cap. NaN-ifelse R semantics and choose rounding also exercise RHS/events.
* All shared and vector-index negative corpora traverse RHS/event validation
  with a missing Python interpreter. Actual S4 structured validators are added
  to the existing ASan/UBSan fuzz target, not a duplicate parser implementation.
* A final type probe reproduced scalar atol strings/booleans/objects/null being
  classified INTERNAL_ERROR (four red cases, test exit 1). The numeric helper
  now rejects these explicitly before conversion/spawn (validation exit 2).

HiGHS MIT full text is already in licenses/scipy/subprojects/highs/LICENSE.txt,
covered by the manifest and assembled THIRD_PARTY_NOTICES. S4 adds an exact-text
coverage assertion, and the existing regeneration gate remains required.

## Gaps and historical measurements

No fit-SIR-by-nested-ODE operation: safe expressions cannot call solvers inside
least-squares residuals; a separately budgeted fixed model would be required.
rcli/base R has no same-solver generic HiGHS/ODE operation; expression parity uses
the S3 R corpus. No R package or scientific wheel is added. amd64 is unverified.

Pre-review cap and acceptance measurements remain in measurement-s4-*.json and
the original S4 section of timings.md, explicitly historical for that image.
Review-fixed image measurements and acceptance are in review-s4-fixes.md and the
S4 review section of timings.md. The benchmark fixtures are allocation probes at
each cap, not universal complexity guarantees for arbitrary MILPs.

S7 API migration: all successful file writes use `outputs_in_artifact:true` and
`artifacts[name]` with `{ref,path,format,key,dtype,shape,nbytes}`; see README.
Tensor fields moved into that map; whole-file table/model/export descriptors have
null key/dtype/shape. Legacy descriptor layouts are removed.
