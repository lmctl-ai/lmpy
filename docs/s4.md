# S4: LP/MILP + ODE

Two fixed SciPy paths, no new wheels: optimize.linprog(method=highs, integrality)
and integrate.solve_ivp. Inputs/caps/defaults/statuses are in README and the
regenerated schema. New ops are statically write to support optional/automatic
artifacts without bypassing readonly/dryrun. This differs from S3's pure reads.

The C++ frontend validates matrix shapes, finite values, aggregate matrix-entry
and row budgets, closed integrality/bounds and numerical controls before spawn.
ODE RHS/event text goes through the existing parser, with y's vector dimension
known; reducers disabled. Named state/parameter aliases obey S3 collision rules.
Python re-validates the AST with the existing postfix builder and fixed function
objects, preserving the R semantics pinned by S3. No string-to-code path added.

ODE uses solve_ivp with a subclass of one of its six closed OdeSolver classes.
The wrapper counts accepted steps and snapshots their time/state, leaving solve_ivp
in charge of interpolation, tolerances, Jacobians and root finding. A Guard tick
precedes every scalar RHS component and event value, including initialisation,
finite-difference Jacobians and event bisection. Native nfev/njev/nlu are retained
in finally blocks even when a callback interrupts a step; rhs_calls includes
Jacobian calls that SciPy excludes from its nfev. Budget stops return initial +
last accepted state and flag partial_trajectory; rejected trial states are never
presented as accepted output. Earlier event history is unavailable on an exception.

Uniform t_eval bounds stored trajectory memory; <=10000 grid points and <=200000
potential output numbers, including a final-point/event reserve, are checked before
spawn. Up to four event callbacks each have a fixed 32-root ceiling (implemented
using solve_ivp's supported positive terminal-count setting); reaching a ceiling
is EVENT_LIMIT, not OK. User terminal events are OK/event termination, with final
state taken from the localized root rather than the enclosing accepted step.
Every nonfinite RHS/event/trial/accepted state stops with NON_FINITE.

HiGHS has a native time/node/iteration budget; no Python callback can interrupt a
single native call. The 30-second cap and process-budget margin keep the hard
kill as a last layer. Fixed threads=1/parallel=false are forwarded by the pinned
SciPy HiGHS adapter; only its known fixed-option warning is suppressed. No caller
option map is accepted. SciPy maps native solution limit to status 4; it is a
NODE_LIMIT domain stop, with the original message and scipy_status retained.
No negative native iteration count is exposed. Primal results are checked for
finiteness, bounds, constraints and integrality; a failed check downgrades OK.
Maximize changes objective/dual/dual-bound signs back to the caller's convention.
Dual vectors are LP-only; MILP incumbent/gap metadata never pretends to be LP duals.

All large vectors (including slack/duals/events) are in one F64 safetensors
artifact. Only fixed tensor markers cross the worker response; C++ validates raw
sizes/dtypes/shapes and atomically installs the artifact after summary checks.
An explicit out with no LP primal fails; automatic outputs are created only when
there are vectors to store. ODE interruption snapshots can still be written with
a non-OK domain status. Responses remain byte-bounded and token economical.

## Independent oracles

* Wyndor hand optimum (2,6), objective36; diet/production intersection (2,1), cost4.
  Degenerate LP checks objective/feasibility, not a particular nonunique x.
* Inequality/equality/bound marginals checked by perturbing RHS/bounds. Binary
  knapsack enumerates every subset; 3x3 assignment enumerates every permutation.
* Decay exp(-t) for every method; backward decay; oscillator cos(t)/-sin(t) and
  energy; Lotka-Volterra H=d*x-g*log(x)+b*y-a*log(y), DOP853 rtol1e-10, drift<1e-6.
* Robertson at t40: primary ODEPACK DLSODA example in
  https://netlib.org/odepack/opkdmain.f, line3931, SHA256
  da31255ff43e3a13c2c0ccaed51c3cd260b8ac9d9082f34b8587c9007d9a2376.
  Printed (0.7158403, 9.186334e-6, 0.2841505) comes from its loose RTOL1e-4 run;
  printed digits are **not** certified accuracy. Tests use 3e-5 /2e-9 /3e-5 absolute
  tolerances justified by that source accuracy, plus mass conservation1e-11.
  Both BDF/Radau run at rtol1e-10/atol1e-13. The primary-source extraction is kept
  in tests/fixtures/robertson-source.json; acquired only during image build.
* Ball fall terminal root sqrt(2*h/g), time and root state; zero event reaches the
  event cap. NaN-ifelse R semantics and choose rounding also exercise RHS/events.
* All shared and vector-index negative corpora traverse RHS/event validation
  with a missing Python interpreter. Actual S4 structured validators are added
  to the existing ASan/UBSan fuzz target, not a duplicate parser implementation.
* A final type probe reproduced scalar atol strings/booleans/objects/null being
  classified INTERNAL_ERROR (four red cases, test exit 1). The numeric helper
  now rejects these explicitly before conversion/spawn (validation exit 2).

HiGHS MIT full text is already in licenses/scipy/subprojects/highs/LICENSE.txt,
covered by the manifest and assembled THIRD_PARTY_NOTICES. S4 adds an exact-text
coverage assertion, and the existing regeneration gate remains required.

## Deviations and gaps

* Safetensors instead of Parquet tables: binding no-new-wheels/S4 instruction and
  existing S1 interchange. y is rows x states; state_names gives the column order.
* Static write access even for inline calls, so dryrun actually simulates; a
  separate read-only variant can be added later if needed. Large results use a
  unique cwd artifact without requiring a caller-provided out.
* ODE output defaults to a uniform grid instead of saving an unbounded adaptive
  mesh. Event records and accepted steps have explicit additional caps/statuses.
* LP limit statuses also distinguish NODE_LIMIT/ITERATION_LIMIT, rather than
  falsely calling every native resource stop a time limit or numerical failure.
* No fit-SIR-by-nested-ODE recipe: the safe expression language has no solver-call
  node, and least_squares accepts expressions rather than arbitrary callbacks.
  Re-running ode_solve per candidate parameter cannot be composed inside S3's
  solver without a new, separately budgeted fixed model operation. No caller code
  or hidden callback is introduced to simulate that composition.
* rcli/base R has no generic ODE/HiGHS LP/MILP op; this is new solver capability,
  not an asserted same-solver cross-tool oracle. Expression parity continues to
  use S3's R-generated semantics corpus; see docs/parity.md. No new R package is
  installed. amd64 execution remains unverified.

## Hardened-container cap measurements

The final aarch64 runtime was exercised with the production wall: no network,
two CPUs, 4 GiB memory, 128 pids, read-only root, dropped capabilities,
no-new-privileges, Docker's default seccomp and a 512 MiB noexec tmpfs. The probe
harness and its NumPy arrays are included in the cgroup peak of **103346176 bytes
(98.56 MiB)**. All four calls exited 0 with domain OK, independently checked
objectives/final states, and responses smaller than 2 KiB:

| Workload | Size | Seconds | Expected result |
|---|---|---:|---|
| Dense-entry cap | 500 x 400 = 200000 entries | 0.815 | objective -400 |
| Variable cap | 390 x 512 = 199680 entries | 0.856 | objective -512 |
| Constraint-row cap | 4096 x 48 = 196608 entries | 1.000 | objective -48 |
| State/output cap | 32 states, 5926 grid points, 195558 trajectory numbers | 0.732 | each final state exp(-1) |

The LP fixtures have bounded variables and repeated dense sum constraints; they
measure allocation at each cap, not worst-case branch-and-bound complexity.
Native time/node limits still bound hard integer problems. The ODE artifact is
1564608 bytes and the callback counter is 2944. Its grid is the largest allowed
for 32 states after the endpoint/event reserve. These are container-local probe
latencies under concurrent acceptance load, not the sequential shim timings.
Raw command, cases and exit code: measurement-s4-caps.json; harness:
scripts/measure-s4-caps.py.
