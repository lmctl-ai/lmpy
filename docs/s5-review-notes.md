# S5 review dispositions (Opus, Fable, Astra; fixes in f7b6905 and 09356e2, red tests in 0328c6e)

Every finding was accepted; regression tests are in `tests/s5_ops.py::ReviewS5` (red before the fix, green after).

| Finding | Disposition |
|---|---|
| Opus 1 (MAJOR) ARIMA OOM at the caps | Fixed. `n * states^2 <= 2.5e7` is checked in the worker right after the series is loaded and before the model is built (`INPUT_TOO_LARGE`, exit 2). It is **not** a pre-spawn check: n is only known after the CSV/frame is parsed, and lmcpp does not parse them for this op. Measured in the hardened container (4 GiB, 2 CPUs) at the bound: states 55, n 8264: no crash, peak cgroup memory 2.59 GB; states 30, n 20000: 2.59 GB. Previously the reproducer was SIGKILLed at 3.4 GiB. |
| Opus 2 (MAJOR) GLM `OK` with invalid mean / NaN llf | Fixed: fitted means are checked against the family support (mu > 0 poisson/gamma, 0..1 binomial, finite gaussian) and llf/deviance finiteness; failure is `NUMERICAL_FAILURE` with NA uncertainty. |
| Opus 3 OLS `OK` with Inf SE on overflow | Fixed: non-finite ssr/llf/bse give `NUMERICAL_FAILURE`, NA uncertainty. |
| Opus 4 GLM `RANK_DEFICIENT` masks `NO_CONVERGENCE` | Fixed: more severe statuses win, `rank_deficient: true` is reported; the `_to` twin writes only for OK/RANK_DEFICIENT so nothing is written for the non-converged run. |
| Fable 1 (MAJOR) gaussian/gamma GLM z-based | Fixed: `use_t` defaults to true for gaussian/gamma with nonrobust covariance; gaussian GLM now equals `sm_ols` to 1e-8 relative (tested), gamma p-values equal scipy t-tails of R's coefficient/SE. README corrected. |
| Fable 2 ARIMA 3e-5 | Fixed and traced (docs/oracle-findings.md item 2): finite-difference score stalls L-BFGS; Nelder-Mead polish added. Fable's diagnosis was right; tightening `pgtol`/`factr` alone did not work (measured), so the polish was used. |
| Fable 3, 4 (docs) | Done: gamma llf/AIC numbers, `n_iter` vs R `iter`, no-prediction note (README, oracle-findings); `test_ar1_agrees_with_yule_walker` renamed `test_ar1_sanity_check_near_yule_walker`. |
| Astra 1 (MAJOR) robust F singular / wrong df | Fixed: F and p are `NaN` for rank-deficient designs and when the robust covariance has effective rank below the number of restrictions (e.g. 2 clusters, 2 slopes). A pseudoinverse F on the estimable subspace was not implemented: the model space is the same as the reduced model, and reporting NaN is explicit and cheap. Full-rank HC0 F still equals the independent 40.04895400436704. |
| Astra 2 (MAJOR) ACF NaN/inaccurate at scale | Fixed: series divided by its largest magnitude before `acf`/`pacf`; non-finite results are `NUMERICAL_FAILURE`. Tested at scales 1e-300 .. 1e300 against the scale-free reference (1e-12). |
| Astra 3 patsy licence label | Fixed in `scripts/notices.py`, notices regenerated byte-for-byte. |

Declined: none. The one deviation from the reviews' wording: Opus 1's "bound before spawn" is done in the worker (see above).
