# S2: typed pandas frames

S2 implements frame_import, frame_inspect, frame_export, frame_select,
frame_groupby and frame_resample. Pandas 2.3.3 and its minimal pinned dependencies
are hash-locked for cp312 aarch64 and amd64; amd64 resolution is not execution.
The numerical ops retain lazy imports and report pandas unloaded.

The Lead's S2 instruction supersedes decisions.md's `.npz`-free / Parquet design:
tables use a single stored-only NPZ. Compressed ZIP entries, encryption, multi-disk
archives, ZIP directory extras/comments, duplicate members, path-bearing names,
overlap/gaps and oversized entries are rejected. NumPy's local ZIP64 *size extra*
is accepted only when its two lengths exactly match the bounded central directory;
ZIP64 central directories are not needed for <=256MiB artifacts. Every member is
a rank-one C-order NPY v1 of bounded size; supported storage is i8/f8/b1/u1/Sn,
never object. C++ checks before spawn and again before atomic output installation.
The metadata JSON has a depth limit of 32 and byte limit of 1MiB; rows <=2M.
Python validates exact member sets, dtype policies, category codes, NA masks and
column lengths with allow_pickle=False; saving also explicitly disables object serialization. Fixed-width UTF-8 storage is budgeted across all columns before NumPy allocates it. ZIP CRC checking is performed by NumPy's
ZIP reader on load. Strings are UTF-8 byte arrays, datetime storage is epoch ns,
nullable ints/bools and float nulls have separate bool masks; category storage is
integer codes with explicit ordered levels. No hidden index crosses calls.

Input CSV is UTF-8/BOM-aware, RFC-style quoted with LF/CRLF, 256MiB maximum,
1MiB fields and <=256 unique nonempty UTF-8 column names. C++ counts rows and
rejects ragged data before copying the bounded input into the private tmpfs.
Python's closed csv.reader decodes cells; custom conservative inference avoids
pandas silently rounding out-of-range integer columns or converting float overflow
into infinity. Inference is returned, and explicit dtype policies remove guessing.
Datetime parsing is ISO only. CSV default-empty means missing even when quoted;
CSV export cannot preserve full type/NA/category identity, so NPZ is canonical.

Exactly one import source is required. Transform ops and import require out and
are statically write operations. Export is also statically write even when inline,
so readonly consistently blocks it. Existing paths are CONFLICT, anonymous
O_TMPFILE plus fsync/linkat installs complete files without replacement. All fixed
per-call filenames are covered by native signal cleanup; container tmpfs remains
the boundary for SIGKILL/OOM. Worker never receives final output paths.

Predicate values are checked against the column dtype, including float nonfinite tokens and ISO datetime awareness. isnull uses the persisted mask rather than combining null with NaN; comparisons exclude masked null cells. Predicates use a closed structured tree, <=32 levels /256 nodes, literal string
methods only. Aggregate caller names select our function objects; std/var ddof=1,
first/last skip nulls. Output column names are column__function; collisions fail.
Groups use observed categories and sorted keys; keys and bins are plain columns.
Pandas reductions follow pandas missing/NaN semantics, while persisted float masks
retain null separately from an explicit NaN. Numeric describe likewise follows pandas.

Resample rules are 1..10000 plus min/h/D/W/MS/ME/QS/YS. Default label and closed
are left (also W); no caller offset objects or regex syntax. Bin count is estimated
conservatively before allocating the grid, and the final output cap is checked.
NaT in time keys is refused. Nine explicit IANA timezone names are supported, as
listed in README. Pandas uses pinned pytz; zoneinfo's path is emptied so its fallback
uses pinned tzdata. Aware ISO offsets must include an explicit dtype tz; naive
local ambiguous/nonexistent DST times fail validation, not silent adjustment.

Tests were added red first (unknown ops and missing pandas), then extended with
fall-DST/aggregate/pre-spawn reproductions that were red against the first draft.
The direct pandas oracle is independent of worker helpers; hand tables certify
region sums, variance, order and spring/fall hourly bins. Tests also cover dtype
matrix round trip (including int64 extremes, NaN vs null, NaT, Unicode and ordered
categories), CSV BOM/CRLF/quotes/ragged/huge numbers, predicate-looking literals,
rule injection, readonly/dryrun, conflicts and hostile NPZ. ASan/UBSan fuzz drives
the actual C++ ZIP/header/metadata, CSV, rule and predicate code with 10000 ZIP
mutations and 10000 other cases; a substantial fraction of structurally valid
ZIPs reaches the end of preflight rather than dying at the signature.

Deviations: stored-only NPZ rather than compressed NPZ/Parquet; fixed timezone
subset rather than all IANA zones; conservative custom CSV inference rather than
pandas implicit inference; transform results always persist and return small
previews; export without out is permitted only for small tables but stays write.
No merge/pivot/rolling, formulas, arbitrary offsets, regexes or optional accelerators.
The audit guard remains defence in depth, not a Python sandbox; Docker is the wall.
No cross-tool lmda execution: the specified checkout is absent (see parity.md).
