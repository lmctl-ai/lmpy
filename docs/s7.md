# S7: interpolation, signal processing, spatial

README has the parameter table, statuses and conventions. This note records the design decisions and the evidence behind them.

## Shape of the slice
* `py/s7.py` (assembled after `ml.py`, before `worker.py`) holds seven worker functions; `src/s7.hpp` holds the validators and the registration of the 14
  operations (`op` and `op_to`). The worker receives arrays as `.npy` files written by C++ after it loaded, shape-checked and finite-checked them.
* Imports are lazy per group: `interp_*` imports `scipy.interpolate` (which pulls in `scipy.spatial`), `sig_*` imports `scipy.signal` (which pulls in interpolate,
  spatial and stats), `spatial_*` imports `scipy.spatial` only. `meta.scipy_subpackages` reports what is loaded; tests assert it.
* Write twins follow the S1/S5 pattern: `output_prefix` raw tensors, C++ builds the safetensors, exclusive `out`, nothing written for a non-OK status.
* Nothing caller-supplied reaches a library as code or free-form options: kernels, windows, metrics, filter families and boundary conditions are enums,
  QHull options are a fixed table chosen in C++ (`Qt`, `Qbb Qc Qz Q12 Qt`, `Qbb Qc Qz Q12`, plus `Qx` above 4 dimensions), `p` is a number or `"inf"`.

## Caps (all enforced in C++ before spawn; the worker repeats the ones a corrupted request could break)
| Quantity | Cap | Why |
|---|---|---|
| input arrays | 200000 numbers (inline 1000) | shared loader |
| filter order | 20 (band filters: 2*order poles, <=20 sections) | `ba` is never produced; SOS stays well conditioned |
| `freqs` | 200 | inline result budget |
| nperseg / nfft | 65536 / 131072 | FFT memory |
| rbf nodes x dims | 5000 x 8 | O(n^3) solve: 7 s and 0.28 GB measured at 5000 |
| knn dims / k / pairs | 32 / 1000 / `max_pairs` <= 1,000,000 | |
| hull dims | 2..6, point caps per dimension and kind (README) | cyclic-polytope facet counts |
| dist pairs | n*m <= 1,000,000 | 8 MB matrix |
| inline results | ~900 numbers | the shared 1000-number rule |
| artifact results | 1.9 M numbers | C++ refuses worker output above 2 M; the worker fails cleanly first |

## Honest statuses
* Missing/duplicate/unsorted nodes are errors before any work (`DUPLICATE_X`, `NOT_INCREASING`); extrapolation is explicit (`BAD_RANGE`).
* RBF checks its own fit at the nodes: a system that is singular is `SINGULAR`; one that is numerically unusable (fit error > 1e-6 of the data scale) is
  `ILL_CONDITIONED`; neither returns values.
* A filter is applied only if every pole is strictly inside the unit circle (`UNSTABLE` otherwise). In seven extreme designs (order 20, tiny bands) scipy's
  SOS poles stayed inside the circle (largest radius 1 - 2.4e-9), so `UNSTABLE` is a defensive status that no input of the suite reaches; the reachable
  warning is `marginal`.
* QHull errors, too few points and degenerate geometry are `DEGENERATE` with the QHull message (first 300 bytes). Write forms of every non-OK status fail with
  that status as `tool_code` and write nothing.
* Distances that are NaN/Inf make the whole answer `UNDEFINED` (with a count) instead of returning NaNs inside a matrix.

## Oracles (independent of the code under test)
* Interpolation: a cubic polynomial and its derivatives/integral are reproduced exactly by the not-a-knot spline (closed forms); natural/clamped/periodic end
  conditions checked on the spline's own derivatives; linear vs the hand formula, slope and trapezoid integral; PCHIP monotonicity and no overshoot; Akima lines
  and step data; smoothing spline limits (a line stays a line for any lam, lam = 0 interpolates, lam = 1e6 equals `numpy.polyfit`); RBF reproduces linear
  functions exactly (thin plate, cubic, quintic) and interpolates its nodes.
* Filters: digital Butterworth magnitude `1/sqrt(1+(tan(pi f/fs)/tan(pi fc/fs))^(2n))` for orders 1..12 lowpass and highpass (1e-8 relative), -3 dB at the cutoff
  (1e-12), Chebyshev ripple floors, Chebyshev II/elliptic stopband, one-pole impulse response by recurrence, zero-phase property of `sosfiltfilt` on a sinusoid
  (output = |H|^2 x, while `sosfilt` lags).
* Spectra: Parseval for the periodogram (sum of the density times df = mean square, 1e-12), on-bin tone amplitude A^2/2 under `spectrum` scaling, `csd(x,x) = welch(x)`,
  coherence of a signal with a scaled copy = 1, coherence in [0, 1] for independent noise, 90 degree shifted tones give a purely imaginary cross spectrum.
* Peaks: sums of Gaussians with known centres, heights, FWHM = 2 sqrt(2 ln 2) sigma, prominence equal to the height of an isolated peak, plateau and edge rules.
* Neighbours: brute force for p = 1, 2, 3.5, inf; radius counts and index sets; the reported index really has the reported distance; ties compared by distance.
* Hulls: unit square (area 1, perimeter 4), unit cube (1, 6, 8 vertices, 12 triangles), regular tetrahedron, octahedron (4/3), 4-cube (1), 5-simplex (1/120);
  Delaunay: Euler count `2n - 2 - h`, volume = hull volume, empty-circumcircle property by brute force, cube volume; Voronoi: vertices are the Delaunay
  circumcentres (closed form), ridge count from Euler's formula.
* Distances: hand-computed tables for every metric.
* Cross-tool recipes: `oracle-interp.lms` (rcli `interp_approx` / `interp_spline`), `oracle-spectrum.lms` (lmda `series_spectrum`); results in `oracle-findings.md`.
