# S6: bounded scikit-learn

`ml_fit`, `ml_predict`, `ml_cv` use scikit-learn 1.7.2, joblib 1.5.2 and threadpoolctl 3.6.0. Both architecture wheel locks include hashes; only aarch64 is executed here. No new serialization dependency. Scientific imports remain lazy: non-ML operations never import sklearn.

## Inputs and preprocessing

Exactly one `columns`, `records` (<=1000 cells), comma-delimited UTF-8 `csv`, or S2 `frame` NPZ. Ordered `features` are explicit. Supervised families require `target`; group CV requires `groups`. Rows <=20000, raw/encoded cells <=200000, raw/encoded features <=64, classes <=32, names/categories/labels <=64 UTF-8 bytes. CSV <=16MiB; NPZ/model <=32MiB. No missing/NaN/Inf values: no silent dropping or imputation, including classifiers which could otherwise accept NaN. Numeric values have absolute value <=1e12; classification labels are strings or integers with absolute value <=1e9. Datetimes need explicit caller encoding.

Required `preprocess: {scale: boolean, one_hot: [feature names]}`. Numeric features promote to float64; int64 and float64 inputs share the `numeric-f64` policy. One-hot features stringify integer labels and preserve string labels (categorical features stay string typed; see the class-label policy below). Levels are sorted, full dummy coding, <=64 total encoded columns. Unseen levels fail. Scaling uses training mean/population variance; constant columns have scale 1. Every CV fold learns categories and scales from its training rows only. Extra input columns are allowed (e.g. the target); missing model features fail before spawn. Column-map key order never reorders the model's feature order.

## Families and hyperparameters

The complete, shared typed tables/defaults/ranges are in `ml-spec.json`, embedded into C++ and sent privately to the worker. Unknown keys (including n_jobs, solver, backend and callable parameters) fail before spawn.

| Family | Parameters |
|---|---|
| linear | fit_intercept |
| ridge | fit_intercept, alpha; fixed SVD solver |
| lasso / elastic_net | fit_intercept, alpha, max_iter, tol; elastic_net also l1_ratio; cyclic coordinate updates |
| logistic / linear_svc | fit_intercept, C, max_iter, tol, class_weight none/balanced; fixed lbfgs / dual=auto |
| gaussian_nb | var_smoothing |
| lda | n_components (0 means auto); fixed SVD |
| knn_classifier / knn_regressor | n_neighbors <=128, weights uniform/distance; fixed brute Euclidean |
| kmeans | n_clusters <=32, n_init <=10, max_iter <=300, tol; fixed Lloyd |
| pca | n_components <=32, whiten; fixed full SVD |
| standard_scaler | no hyperparameters (separate from optional preprocessing) |
| random_forest_classifier / regressor | n_estimators <=64, max_depth <=12, min_samples_leaf, max_features sqrt/log2/all, bootstrap |
| hist_gradient_boosting_classifier / regressor | max_iter <=100, max_depth <=12, max_leaf_nodes <=31, min_samples_leaf, learning_rate, l2_regularization; early_stopping=false |

All estimator n_jobs values are fixed at 1; joblib's backend is sequential; BLAS/OpenMP pools are limited to 1 and reported. Threadpoolctl's Linux libc lookup uses the loaded process symbols instead of spawning ldconfig. The existing import guard and audit hook (including the deserialization class-resolution event) remain defence in depth, not a sandbox. The hardened container is the boundary.

Seeds (uint32) are required for stochastic estimators and every CV. A generator is echoed only when the estimator or shuffled CV consumes randomness, as **sklearn RandomState(MT19937)**: sklearn's integer-seed API does not use PCG64. No false PCG64 claim. Deterministic families may omit seed; fixed lbfgs logistic is deterministic and ignores an optional seed. Unshuffled deterministic CV still requires/echoes its seed for a stable interface but has no generator field.

## Models and predictions

Persistable fit requires exclusive `out: *.safetensors`. Single-file v1: exact family attribute table, F64 fitted numeric arrays, I64 class codes, optional preprocessing mean/scale. Metadata string entries include version, sklearn version, feature order/dtype policy, learned categories, parameters, original class labels, dimensions, training seed, target, training SHA256 and both-locks digest. No object arrays or executable state. All attributes, shapes, dtypes, finite values, dimensions and preprocessing metadata are validated before spawn; extra/missing attributes and truncated files fail. Version skew fails unless `allow_version_skew:true` (reported explicitly, without promising compatibility).

LinearSVC stores coefficients; bounded brute KNN stores training X/y and reconstructs a fresh brute estimator. These implement the current S6 request, superseding the older Fable exclusions. Original labels map to sorted integer codes internally. Trees **cannot persist** (`MODEL_NOT_PERSISTABLE`): fit requires `predict_frame` NPZ and exclusive `predict_out` NPZ in one call, without `out`.

`ml_predict` requires exclusive NPZ `out`; kinds predict, predict_proba, decision_function, transform are checked against the family. Row order is preserved. 1-D output column is `prediction`; matrices use probability_i / decision_i / component_i (the response echoes class order and feature order; binary decision_0 is positive for classes[1]). Fit's `prediction_preview` is the first <=20 training rows; prediction artifacts include a bounded preview. All summaries <=1000 array elements /64KiB; ML preview alone <=800 cells /24KiB. Small fitted parameters appear under `parameters` only when their complete eligible tensor set is <=100 values and the whole response stays within the array/byte budgets; otherwise `parameters_omitted:true`. Training X/y and class-code tensors are never echoed. Large model parameters stay in the artifact. Within one image and CPU family, save/load predictions match the original fitted estimator bit-for-bit.

Write operations honour readonly/dryrun, exclusive/atomic install, workspace confinement and temporary cleanup. `ml_cv` is read-only. No successful write without its artifact.

## CV and budgets

Supervised families support kfold / stratified / group / timeseries, 2..20 splits. Shuffle is explicit (not supported for timeseries); seed always required. Classifier metrics: accuracy, f1_macro, binary roc_auc (probability-capable family), log_loss. Regressor metrics: mse, mae, r2. Undefined metrics return UNDEFINED_METRIC with metric, fold_index, completed_folds, missing_classes and a split recommendation; a training fold with fewer than two classes returns INSUFFICIENT_CLASSES. Completed prior folds are retained; no silent finite replacement. Backend numerical ValueError returns NUMERICAL_FAILURE; only explicit input checks produce validation errors. Per-fold scores, population mean/std (ddof=0); full test indices only for <=600 total row*fold entries, otherwise SHA256 of little-endian I64 indices with `indices_omitted:true`. Unsupervised CV is deferred: no agreed held-out metric/scoring policy for scaling/PCA/clustering in S6.

Pre-spawn work product <=200M: rows * encoded features * iterations * restarts * clusters * trees * depth * folds (only parameters present in that family apply; logistic/SVC/tree classifiers also multiply by class count); direct linear algebra uses rows * width^2 * folds. KNN prediction/CV pair budget <=5M. Prediction uses saved encoded width, not the levels in the current batch; both encoded-input and output cells are capped before spawn. Component/cluster/neighbor counts cannot exceed training dimensions. Prediction batches, including a single row, are independent of those fit-size constraints; saved model parameters are checked against saved training dimensions. Limits combine; the maximum of every independent dimension is not simultaneously allowed.

Shared ML-computation SIGALRM time_limit >0..30s (default 10), additionally bounded by hard process timeout minus import/10s reserve. Python callbacks stop at Python boundaries; a long native call can delay the signal, so conservative work caps are also required. TIME_LIMIT and NUMERICAL_FAILURE are honest domain statuses; writes fail without artifacts. Classifier scores/probabilities and centroid distances must be finite before a label is accepted (an argmax label alone can hide overflow). The same guard is used for held-out CV predictions. A deficient linear design returns RANK_DEFICIENT with rank/rank_deficient and still writes its usable minimum-norm model. Too few distinct kmeans points returns DEGENERATE_CLUSTERS; a zero within-class LDA design returns DEGENERATE_DATA, both without an artifact. Other ConvergenceWarning => NO_CONVERGENCE. Kmeans reaching its iteration cap is conservatively NO_CONVERGENCE even if convergence happened on that last iteration. Fixed-budget forests/boosting are finite training algorithms, not claimed optimizer convergence.

## Deviations and remaining scope

* sklearn uses MT19937 for integer seeds, not the design's general PCG64 convention; the actual generator is echoed.
* `features` stores ordered names; a separate `feature_dtypes` metadata map records the numeric-f64/string policies. Original string/integer class labels live in bounded JSON metadata, with I64 class codes in the tensor; no variable-length/object tensor is necessary.
* Version matching is exact (including patch), stricter than the proposed minor-version check. Explicit skew acceptance is still available.
* CV scoring is supervised only; unsupervised held-out scoring needs an agreed metric policy. Preprocessing is learned per fold, never once on the full dataset.
* NPZ ML sources reject datetime columns, even unused ones; select only ML columns with `frame_select` first. CSV unused datetime-looking columns remain ordinary strings.
* The native-work budget is cooperative at Python boundaries, not a preemptive native instruction counter. The container's hard timeout remains the final bound.

## Objective and label conventions (S6 review)

The intercept is unpenalized for linear/ridge/lasso/elastic_net and fixed lbfgs logistic. With n rows and residual r = y-Xw-b:

* Ridge minimizes `||r||² + alpha ||w||²` (no division by n).
* Lasso minimizes `(1/(2n)) ||r||² + alpha ||w||_1`.
* Elastic net minimizes `(1/(2n)) ||r||² + alpha*l1_ratio ||w||_1 + alpha*(1-l1_ratio)/2 ||w||²`.
* Binary logistic minimizes `0.5 ||w||² + C sum(logloss)`; equivalently `w + C X' (p-y) = 0` and `sum(p-y)=0` at the optimum. Class weights, when requested, weight that sum. LinearSVC uses liblinear's regularized synthetic intercept convention instead.

For glmnet with `standardize=FALSE`, sklearn lasso/elastic_net alpha equals glmnet lambda and l1_ratio equals glmnet alpha; ridge `alpha_sklearn = n * lambda_glmnet`. With `scale:true`, penalties apply to standardized coefficients. GaussianNB stores per-class means and population variance plus `var_smoothing * max(global population variance)`. PCA uses `s²/(n-1)` and fixes each component's max-absolute loading positive, matching the sign-adjusted NumPy SVD row convention.

Class labels use one source-independent policy: canonical decimal integers (`0` or `-?[1-9][0-9]*`, magnitude <=1e9) become integer labels, including strings in inline/CSV/table sources. Leading zeros, plus signs and other text remain string identifiers. All labels in a column must share one input type; outputs/classes preserve the canonical type. Add an alphabetic prefix when numeric-looking strings must remain text. Categorical feature typing is independent of class typing.

For kNN, equal class votes choose the first class in sorted label order. Equal distances at the kth neighbor use training-row order in the pinned brute implementation; changing training order may therefore change a tied prediction. Stored classifier training codes must cover every persisted class exactly as a set; reconstruction and probability width are checked independently. Rank-reduced LDA persists only its actual SVD axes, reports `components`/`components_reduced`, and reconstructs that exact transform even if more axes were requested. New strict KNN classifier models include `classes_`; older S6 prototype KNN files lacking it are refused as BAD_MODEL and must be refitted. Safetensors validation provides structural/cross-attribute consistency, not authentication of finite coefficient edits.
