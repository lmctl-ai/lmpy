# S5: statsmodels (OLS/WLS, GLM, SARIMAX, ACF)

See README for parameters, limits and statuses. Pinned statsmodels 0.14.6 (the 0.14.x line lmstats was ported from), patsy 1.0.3 and
packaging 26.3, hash-locked in both architecture locks, with licences in `licenses/` and `THIRD_PARTY_NOTICES.md`.

## Design
* **No formula strings.** Models take a JSON term list `{const}|{var}|{cat,ref}|{interact:[..]}|{poly:[col,2..6]}`. lmcpp validates the grammar,
  the name alphabet and all caps before a worker exists. The worker builds the design matrix with numpy and calls only the array APIs
  (`OLS/WLS`, `GLM`, `SARIMAX`, `acf/pacf`). Column naming: `const`, `x`, `g[T.level]`, `x1:x2`, `x^2`. The reference level is always explicit.
* **patsy never loads.** `statsmodels.regression.linear_model` imports patsy at module scope, so `sm_import()` installs a stub whose classes
  are unusable, then imports statsmodels; `BlockedImports` and the audit hook block `patsy`, `formulaic` and `statsmodels.formula*` afterwards.
  Every response carries `meta.forbidden_modules_loaded` (always `[]`); `tests/s5_ops.py::Isolation` asserts `"patsy" not in sys.modules`
  after each sm op. patsy is nevertheless shipped (statsmodels metadata requires it) and listed in the notices.
* **Missing data** are handled by `na_action` (`error` default, `drop`), never silently. Singular designs return `RANK_DEFICIENT` with the rank
  and, for the write twins, still write the bundle. GLM reports IRLS status (`converged`, iterations) and `PERFECT_SEPARATION`.
* **Budgets.** Rows <= 200000, design columns <= 256, design cells <= 10M, ARIMA state dimension <= 64 and <= 24 parameters; all rejected
  before spawn. The worker uses a cooperative SIGALRM budget (`timeout - 10 s`, minus import time) and returns `TIME_LIMIT`.
* Inline results hold <= 1000 array elements; larger output needs the `_to` twin (safetensors bundle).

## Oracles (independent of pycli)
* NIST StRD **Longley** (certified coefficients, SEs, sigma, R^2) and **Wampler 1-2** are reproduced exactly in `tests/oracle/s5.py`.
  Norris, Filip and Wampler 3-5 data are not reproducible offline here and are not claimed.
* Exact rational WLS/OLS, closed-form HC0-HC3/cluster sandwiches, GLM closed forms (intercept-only Poisson/binomial/gamma, Gaussian = OLS).
* R 4.3.3 golden constants (`tests/fixtures/s5-r-golden.json`, regenerated by `scripts/s5-r-golden.py`); ARIMA vs Yule-Walker/OLS and AIC/BIC by hand.
* Cross-tool recipes and their numbers: `oracle-findings.md`.
