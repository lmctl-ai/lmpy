# pycli status and hand-off (2026-10-19)

## State
- v0.1.0 complete on `main`: C++17 lmcpp front end, spawns `python3 -P -s -B` per call in a pinned offline docker image, hash-locked wheels, hardened host shim `bin/pycli`, 53 base ops, lmapi schema via `--schema` / `--schema --json`.
- `examples/`: 15 `tut-*.lms` tutorial conversions (seeded synthetic data in `examples/data`, regenerated by `scripts/generate-tutorial-data.py`, each recipe asserts a known answer), 7 `cross-*.lms` pycli-vs-R agreement recipes (R legs need rcli locally; local-only in CI), plus the original recipes. Run as `lmscript examples/x.lms` with the shim on PATH (never `lmscript run`).
- Docs: `docs/parity.md`, `docs/oracle-findings.md`; CI lock-drift workflow compares sorted pin+hash lines.
- Repo is PRIVATE. Per the CI rule, private repos are verified locally; keep paid macOS/Windows legs gated with `github.event.repository.private == false`.

## Not done (deliberately)
- Parquet support (needs the large pyarrow wheel).
- The re-engineering requested by the owner: one binary with no Python runtime. **Done on branch `native-dsl` as lmpy (C++, `_dsl_` model): see `durable-memory/native-dsl.md`.** The earlier Rust plan in `durable-memory/native-plan.md` (multicall Rust binary `lmpy`, invoked as `pycli` it serves this tool's byte-identical schema; self re-exec worker with rlimits + seccomp; docker image frozen as test oracle with tolerance tiers; ~38-45 engineer-weeks). Blockers before linking upstream code publicly: lmda Tukey GPL-derived code, lmstats Numerical Recipes routines, WMA/Erlang-A provenance.
- RNG decision: R-identical streams are NOT required; PCG64-style with a statistical guarantee is fine. Do not copy GPL R/Rmath source (clean-room; scipy/statsmodels/sklearn are BSD and may be consulted with notices kept).
